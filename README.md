# 📦 준비물 4개

**설치 문서를 열기 전에 이 4개를 먼저 챙겨두세요.** 전부 각자 알아서 받으면 됩니다.

| | 무엇 | 비용 | 받는 곳 | 왜 필요한가 |
|---|---|---|---|---|
| 1 | **Claude 구독 (Pro)** | **월 $20~** | [claude.ai](https://claude.ai) | ⭐ 이게 없으면 아무것도 안 됩니다 |
| 2 | **GitHub 계정** | 무료 | [github.com/signup](https://github.com/signup) | 팀과 스킬·양식을 주고받는 곳 |
| 3 | **VS Code** | 무료 | [code.visualstudio.com](https://code.visualstudio.com) | 보고서 편집기. 클로드가 고친 걸 보여줌 |
| 4 | **cmux** | 무료 | [cmux.com](https://cmux.com) | 클로드를 돌리는 터미널. 여러 개 동시에 굴릴 수 있음 |

### 챙길 때 참고

**1. Claude 구독** — 가입만 하지 말고 **결제까지** 해야 합니다.
`claude.ai` 로그인 → 왼쪽 아래 프로필 → **Upgrade Plan** → **Pro ($20/월)**.
하루 종일 쓰게 되면 나중에 Max($100)로 올리면 됩니다.
> ⚠️ "API 키"를 따로 살 필요는 **없습니다.** 구독으로 그대로 돌아갑니다.

**2. GitHub 계정** — 가입만 해두고, 아이디를 **팀에 알려주세요.** 초대를 받아야 스킬을 올릴 수 있습니다.
(단, 이 레포를 **받는** 것만은 계정 없이도 됩니다)

**3. VS Code** — 다운로드하면 압축 파일이 받아집니다. 열어서 나온 아이콘을 **응용 프로그램** 폴더로 드래그하면 설치 끝.

**4. cmux** — 맥 전용 터미널 앱입니다. `.dmg` 를 열고 **응용 프로그램**으로 드래그.
맥 기본 "터미널" 앱으로도 전부 되니까, **귀찮으면 건너뛰어도 됩니다.**

**➡️ 4개 다 챙겼으면 → [docs/01-mac-setup.md](docs/01-mac-setup.md) 로 가세요.**

# 뭘 하는 것일까? (30초)

## 클로드 코드 (Claude Code)

터미널에서 돌아가는 AI 비서입니다. 웹 챗봇과 다른 점은 **내 컴퓨터의 파일을 직접 읽고, 쓰고, 저장한다는 것**입니다.

```
> reports/샘플/IR덱.pdf 읽고 이 회사 사업모델 정리해줘
> 그 내용으로 심의보고서 초안 만들어서 reports/○○테크/ 에 저장해줘
```

파일을 읽고 → 문서를 만들고 → 폴더에 저장까지 알아서 합니다.

## 스킬 (Skill)

**"이런 요청이 오면 이 절차로, 이 양식으로 만들어라"** 를 적어둔 파일입니다.
한 번 만들어두면 그 다음부터는 이 한 줄이면 됩니다:

```
> ○○테크 시리즈A 30억 투자 건, 심의보고서 초안 잡아줘
```

→ **우리 회사 목차 그대로**, 숫자 표기 규칙 그대로, 리스크 섹션까지 채워서 나옵니다.
**이 스킬을 만들어 쌓는 게 태엽의 목적입니다.**

| 매번 프롬프트 붙여넣기 | 스킬로 만들어두기 |
|---|---|
| 양식을 매번 다시 설명 | 한 줄이면 끝 |
| 사람마다 결과물이 제각각 | 팀 전원이 동일한 양식 |
| 잘 나온 프롬프트가 대화창과 함께 사라짐 | 파일로 남아 계속 개선됨 |
| 양식 바꾸면 전원에게 다시 공지 | 파일 하나 고쳐서 올리면 끝 |

## ② 아무거나 하나 만들어보게 하기 (10분)

```
> 가상의 스타트업 "○○테크"를 하나 만들어줘.
  AI 기반 물류 최적화 SaaS이고, 시리즈A 30억 투자를 받으려는 상황이야.
  매출, 인원, 시장 규모 같은 걸 그럴듯하게 지어내서
  reports/연습/○○테크_IR요약.md 로 저장해줘.
```

**▶ 이렇게 나오면 성공**
```
파일을 생성하겠습니다.
✓ reports/연습/○○테크_IR요약.md 생성 완료
```

만들어진 파일을 열어보세요. VS Code로 보려면:
```
> 방금 만든 파일 VS Code로 열어줘
```

## ③ 그걸로 보고서 뽑아보기 (10분)

```
> 방금 만든 ○○테크 자료를 바탕으로 투자심의보고서 초안을 만들어줘.
  목차는 딜 개요 / 회사 개요 / 시장 / 재무 / 밸류에이션 /
  투자 포인트 / 리스크 / Exit 전략 / 심의 요청사항 순서로.
  숫자에는 전부 출처 라벨을 붙이고, 확실하지 않은 건 [확인필요]로 비워둬.
```

나온 결과를 보고 **마음에 안 드는 부분을 그냥 말해보세요.**

```
> 리스크 섹션이 너무 형식적이야. 최소 3개, 각각 발생가능성/영향도/대응방안 표로 다시 써줘
```

```
> Exit 전략에 Base/Bull/Bear 3개 시나리오를 MOIC랑 IRR 포함해서 표로 넣어줘
```

**이 왕복이 핵심입니다.** 한 번에 완벽하게 나오지 않습니다. 말로 고쳐나가는 겁니다.

## ④ 이 왕복을 스킬로 굳히기 (5분)

```
> 지금까지 내가 요구한 것들(목차, 출처 라벨, 리스크 표, Exit 3시나리오)을
  전부 반영해서 "투자심의보고서" 스킬로 만들어줘.
  다음부터는 내가 자료만 주면 이 양식으로 바로 나오게.
```

**▶ 이렇게 나오면 성공**
```
✓ Created .claude/skills/투자심의보고서/SKILL.md
```

# 클로드 안에서 자주 쓰는 명령

| 입력 | 하는 일 |
|---|---|
| `/help` | 전체 명령 목록 |
| `/clear` | 대화 초기화. **보고서 하나 끝날 때마다 꼭 하세요** |
| `/skill-creator` | 새 스킬 만들기 (대화형) |
| `/model` | 모델 변경 (Opus = 똑똑함 / Sonnet = 빠름) |
| `/exit` | 나가기 |
| `@파일명` | 파일을 첨부해서 질문 (예: `@reports/A사.md 이거 검토해줘`) |
| `!명령어` | 터미널 명령 바로 실행 (예: `!ls`) |
| `Esc` | 하던 일 중단 |
| `Shift + Tab` | 매번 승인 묻는 거 끄기 |
| `↑` | 이전에 했던 요청 다시 불러오기 |

> 💡 **명령어를 외울 필요 없습니다.** 한국어로 그냥 말하면 됩니다.
> `> 대화 지우고 새로 시작하자` 라고 해도 알아듣습니다.

# ⚠️ 보안 — 이것만 지키면 됩니다

**이 레포는 공개(Public)입니다.** 그래서 실제 딜 자료가 실수로 올라가지 않게 막아뒀습니다.

| | |
|---|---|
| ✅ **안전** | `reports/` 폴더 — **통째로 차단**됨. 여기 넣은 건 내 맥에만 남고 클로드만 읽습니다 |
| ✅ **안전** | `.xlsx` `.pptx` `.docx` `.pdf` `.hwp` — 어디에 두든 커밋 안 됩니다 |
| ⚠️ **주의** | 그 외 위치의 `.md` 파일 — 회사명·실제 숫자를 적었다면 올리기 전에 확인 |

**딜 자료는 전부 `reports/` 안에 넣으세요.** 그러면 신경 쓸 게 없습니다.

확실하지 않으면 클로드한테 물어보면 됩니다:
```
> 지금 올리려는 파일 중에 민감한 내용이 있는지 확인해줘
```
