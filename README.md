## 이게 뭔데? (30초)

**클로드 코드(Claude Code)** — 터미널에서 돌아가는 AI 비서입니다.
챗봇과 다른 점은 **내 컴퓨터의 파일을 직접 읽고, 쓰고, 고칠 수 있다는 것**입니다.
IR덱을 던져주면 읽고, 보고서 파일을 만들어서 폴더에 저장까지 해줍니다.

**스킬(Skill)** — "이런 요청이 오면 이 절차로, 이 양식으로 만들어라"를 적어둔 파일입니다.
한 번 만들어두면 이렇게 됩니다:

```
> ○○테크 시리즈A 30억 투자 건, 심의보고서 초안 잡아줘
```

→ 우리 회사 목차 그대로, 숫자 표기 규칙 그대로, 리스크 섹션까지 채워서 나옵니다.
**이걸 만드는 게 이 레포의 목표입니다.**

```
          ↓

 [6] 돌려보고 고치기         평소 말투로 요청 → 결과 확인 → "이 부분 이렇게 고쳐"

          ↓
      [4]~[7] 반복 — 보고서 종류마다 스킬 하나씩
```

## [1] 필요한 계정 2개

| 계정 | 비용 | 용도 | 가입 |
|---|---|---|---|
| **Anthropic (Claude)** | **월 $20~** | 클로드 코드 로그인 | https://claude.ai |
| **GitHub** | 무료 | 레포 받기 / 스킬·보고서 공유 | https://github.com/signup |

- 결제는 **Anthropic 한 곳만** 하면 됩니다. API 키를 따로 사지 않아도 구독으로 그대로 돌아갑니다.
- 요금제는 **Pro($20)** 로 시작하고, 하루 종일 쓰게 되면 **Max($100)** 로 올리면 됩니다.
- 이 레포는 **비공개(Private)** 입니다. **초대를 먼저 수락**해야 받을 수 있습니다.

## [2] 필요한 프로그램

| 프로그램 | 필수? | 왜 필요한가 |
|---|---|---|
| **Claude Code** | ✅ 필수 | 본체. `curl` 한 줄이면 깔립니다 |
| **git** | ✅ 필수 | 레포 받기 / 팀과 스킬 주고받기 |
| **gh** (GitHub CLI) | ✅ 필수 | GitHub 로그인. 이게 있으면 토큰·비번을 안 만들어도 됩니다 |
| **Homebrew** | 🟡 권장 | 위의 git·gh·VS Code를 한 줄로 깔아주는 도구. 없어도 되지만 있으면 훨씬 편합니다 |
| **VS Code** | 🟡 권장 | 보고서 편집 + 클로드가 고친 내용을 나란히 보여줌 |
| Pandoc / LibreOffice | ⬜ 선택 | 보고서를 Word/PDF로 자동 변환할 때 |
| cmux | ⬜ 선택 | 클로드를 여러 개 동시에 굴릴 때. 익숙해진 뒤에 |

> Xcode 같은 거대한 앱은 필요 없습니다. git이 들어있는 개발도구는 Homebrew 설치 시 자동으로 같이 깔립니다.

→ **설치 명령어 전부: [docs/01-mac-setup.md](docs/01-mac-setup.md)**

## [4]~[7] 스킬 만드는 흐름 (요약)

### ① 재료 준비 — 백지에서 시작하지 마세요

기존에 **잘 쓴 보고서**를 `reports/샘플/` 폴더에 넣습니다. Finder에서 드래그해도 됩니다.

```bash
mkdir -p ~/TY_AI/reports/샘플
```

> `.docx` `.pdf` `.xlsx` 는 실수로 GitHub에 올라가지 않게 막아뒀습니다.
> 내 맥에서만 클로드가 읽습니다.

### ② 스킬로 굳히기

```
> reports/샘플/ 폴더의 투심보고서 3개를 읽어줘.
  공통 목차와 서술 톤을 뽑아서 "투자심의보고서" 스킬로 만들어줘.
  다음부터 딜 자료만 주면 같은 양식으로 초안이 나오게.
```

(또는 `/skill-creator` 를 입력하면 클로드가 인터뷰하듯 물어봐 줍니다)

### ③ 실제로 돌려보기 — ⚠️ 스킬 이름은 말하지 말고

```
> ○○테크 시리즈A 30억 투자 건, 심의보고서 초안 잡아줘
```

평소 말투로 해야 진짜 테스트입니다.

### ④ 그 자리에서 고치기 — 파일을 직접 열 필요 없습니다

```
> Exit 시나리오가 너무 얕아. Base/Bull/Bear 3개를 MOIC·IRR 포함 표로 강제하게 스킬 고쳐줘
```

### ⑤ 만족하면 팀에 공유

```
> 방금 만든 스킬 커밋해서 push 해줘
```

→ **자세히: [docs/02-skill-guide.md](docs/02-skill-guide.md)**

## 클로드 안에서 자주 쓰는 명령

| 입력 | 하는 일 |
|---|---|
| `/help` | 전체 명령 목록 |
| `/skill-creator` | 새 스킬 만들기 (대화형) |
| `/clear` | 대화 초기화. **보고서 하나 끝날 때마다 꼭 하세요** |
| `/model` | 모델 변경 (Opus = 똑똑함 / Sonnet = 빠름) |
| `/init` | 이 프로젝트 규칙(CLAUDE.md) 자동 생성 |
| `/exit` | 나가기 |
| `@파일명` | 파일을 첨부해서 질문 (예: `@reports/A사.md 이거 검토해줘`) |
| `!명령어` | 터미널 명령 바로 실행 (예: `!ls`) |
| `Esc` | 하던 일 중단 |
| `Shift + Tab` | 매번 승인 묻는 거 끄기 |
| `↑` | 이전에 했던 요청 다시 불러오기 |

## ⚠️ 보안 주의

- 이 레포는 **Private** 입니다. 그래도 NDA 대상 자료를 올릴지는 한 번 더 생각하세요.
- `.gitignore` 로 `xlsx / pptx / docx / pdf` 는 커밋되지 않게 막아뒀습니다.
- **`.md` 파일은 막혀 있지 않습니다.** 보고서 본문에 민감한 내용이 있으면 push 전에 확인하세요.
- 확실하지 않으면 클로드한테 물어보세요: `> 지금 커밋하려는 파일 중에 민감한 게 있는지 봐줘`
