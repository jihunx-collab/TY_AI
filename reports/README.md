# reports — 산출물 폴더

## ⚠️ 이 폴더의 내용물은 GitHub에 올라가지 않습니다

이 레포는 **공개(Public)** 이기 때문에, `.gitignore` 로 이 폴더 전체를 차단해뒀습니다.
여기 넣는 파일은 **내 맥에만 남고**, 클로드는 읽을 수 있습니다.

그러니 마음 놓고 넣으세요:

```
reports/
├── 샘플/                    ← 스킬 만들 때 참고할 기존 보고서
│   ├── A사_투심보고서.docx
│   └── B사_투심보고서.md
└── ○○테크/                  ← 실제 작업 산출물
    └── 투자심의보고서_초안_20260907.md
```

Finder에서 이 폴더로 드래그하면 됩니다.

> 만약 이 폴더의 무언가를 굳이 공유해야 한다면, **민감정보를 지운 뒤**
> `git add -f 파일명` 으로 강제 추가해야 합니다. 웬만하면 하지 마세요.
