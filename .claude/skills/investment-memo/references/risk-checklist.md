# 리스크 점검 체크리스트

각 항목을 "해당 없음"으로 넘기기 전에 근거를 확인할 것.

## 시장
- [ ] 시장 규모 추정이 회사 자료 외 제3자 출처로 교차 검증되는가
- [ ] 시장이 실제로 성장 중인가, 아니면 회사만 성장 가정하는가
- [ ] 대체재/우회 솔루션으로 시장 자체가 사라질 여지
- [ ] 경쟁사의 자금력·유통망이 압도적이지 않은가

## 사업·기술
- [ ] 매출 상위 고객 집중도 (1위 고객 비중 30% 이상이면 리스크)
- [ ] 계약이 갱신형인가 일회성인가, 갱신율 데이터가 있는가
- [ ] 핵심 기술이 특정 인력 1~2명에 종속되어 있는가
- [ ] 특허/라이선스 분쟁 이력 또는 침해 가능성
- [ ] 인허가·규제 미충족 항목

## 재무
- [ ] Runway가 이번 투자 후 18개월 이상인가
- [ ] 추정 매출 성장률이 과거 실적 대비 비현실적으로 점프하지 않는가
- [ ] 매출채권 회수기일, 부실채권 여부
- [ ] 우발부채, 소송, 미지급 세금·4대보험
- [ ] 특수관계자 거래
- [ ] 감사의견 (적정 외 의견 여부), 비감사 재무제표라면 신뢰도

## 지배구조·인력
- [ ] 창업자 지분 희석 정도 (동기부여 유지 가능한가)
- [ ] 기존 투자자의 조건이 본건보다 유리한가 (선순위 청산우선권 누적)
- [ ] 공동창업자 간 분쟁 이력
- [ ] 핵심인력 락업/경업금지 확보 여부
- [ ] 스톡옵션 풀 잔여분

## 딜 구조
- [ ] 밸류가 직전 라운드 대비 과도하게 상승하지 않았는가
- [ ] 다운라운드 발생 시 우리 포지션
- [ ] 후속 투자 필요 규모와 조달 가능성
- [ ] Exit 경로가 현실적으로 존재하는가 (해당 섹터 최근 M&A/IPO 사례)
- [ ] 상환권 행사 시 회사가 실제 상환 가능한가

## 자료 신뢰성
- [ ] 회사 제시 수치와 재무제표가 일치하는가
- [ ] 실사 미완료 항목이 무엇인가
- [ ] 확인 불가로 남긴 항목이 투자 판단을 뒤집을 수 있는 것인가
