# 투자심의보고서 작성

## 절차

1. **입력 자료 확인**
   - 사용자가 준 자료(IR덱, 사업계획서, 재무제표, 텀시트, 실사자료) 전부 읽는다.
   - 자료가 없으면 **추측해서 쓰지 말고** 무엇이 필요한지 먼저 물어본다:
     대상회사 / 투자금액·밸류 / 투자형태 / 최근 3개년 재무 / 라운드 정보.

2. **정보 격차 목록화**
   - 목차 항목 중 근거 자료가 없는 부분을 먼저 리스트로 뽑아 사용자에게 보여준다.
   - 사용자가 "일단 초안 잡아줘" 하면 해당 부분은 `[확인필요]` 로 비워두고 진행한다.

3. **작성**
   - 목차는 `references/report-template.md` 를 그대로 따른다. 항목을 임의로 빼지 않는다.
   - 해당 없는 항목은 삭제하지 말고 `해당사항 없음` 으로 남긴다.
   - 결과물 저장 위치: `reports/<회사명>/투자심의보고서_초안_<YYYYMMDD>.md`

4. **자체 검수** — 아래 체크리스트를 통과할 때까지 스스로 고친다.
   - 출처 없는 숫자가 남아있지 않은가
   - 실적/추정 라벨이 전부 붙어있는가
   - 밸류에이션 계산식이 재현 가능한가
   - 리스크가 3개 이상, 각각 대응방안이 있는가
   - Exit 시나리오가 Base/Bull/Bear 3개 다 있는가

5. **전달**
   - 파일 경로와 함께, `[확인필요]` 항목을 목록으로 정리해 보고한다.
   - "이 문서는 초안이며 사람 검토가 필요합니다" 를 명시한다.

## 절대 규칙 (금융 문서)

- **출처 없는 숫자를 쓰지 않는다.** 모르면 `[확인필요]`.
- **모든 수치에 라벨을 붙인다**: `[실적]` / `[회사추정]` / `[자체추정]` / `[2차자료]`
- **모든 재무 수치에 단위와 기준을 병기**: `매출 128억원 [실적, FY24, 별도기준]`
- 자료 원문에 없는 수치를 만들어내지 않는다. 보간·유추도 하지 않는다.
- 계산이 들어간 값(투자단가, 지분율, IRR, MOIC, 배수)은 **계산식을 각주로 남긴다.**
- 시장 규모(TAM/SAM/SOM)는 출처 기관명과 발행연도를 반드시 적는다. 없으면 쓰지 않는다.
- 파일명과 문서 상단에 **"초안"** 을 유지한다. 사람이 검토 후 직접 떼도록 한다.
- 톤: 단정적 홍보 문구 금지. 사실 → 판단 순서로, 판단에는 근거를 붙인다.

## 하지 말 것

- 목차 순서 임의 변경
- 리스크 섹션을 형식적으로 한두 줄 쓰고 넘어가기 (심의에서 제일 먼저 깨지는 부분)
- 회사 IR 자료의 표현을 그대로 옮겨 적기 — 검증된 사실과 회사 주장은 분리해서 쓴다
- 투자 찬반 결론을 사용자 지시 없이 단정하기. 판단 근거를 제시하고 결론은 `심의 요청사항` 으로
