# 팀 공용 스킬 폴더

여기에 만든 스킬은 이 레포에서 `claude` 를 실행하면 **자동으로 인식**됩니다.
커밋해서 push 하면 팀 전원이 `git pull` 로 같은 스킬을 쓰게 됩니다.

## 만드는 법

→ **[../../docs/02-skill-guide.md](../../docs/02-skill-guide.md)**

가장 빠른 방법은 클로드한테 시키는 것입니다:

```
> reports/샘플/ 폴더의 보고서들을 읽고 공통 양식을 뽑아서 스킬로 만들어줘
```

## 구조

```
.claude/skills/
└── 스킬이름/
    ├── SKILL.md        ← 필수. 절차와 규칙. 파일명은 대문자
    └── references/     ← 선택. 보고서 양식, 체크리스트 등
```

`SKILL.md` 맨 위에는 반드시 이 블록이 있어야 합니다:

```markdown
---
name: 스킬이름
description: 언제 이 스킬을 쓰는지. 발동 키워드를 전부 넣을 것.
---
```
